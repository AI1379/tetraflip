# 《109.5°》v3.2 真人盲测协议

本协议只验证 `AGENTS.md` 中不能由 solver、单元测试或截图审查替代的三项真人门槛。受试者必须此前没有看过本项目、规则文档、关卡解或开发演示；开发者只观察和追问，不教学、不纠正。

> **2026-08-29 状态**：当前无法取得足量完整真人首次尝试，故本协议保留为未来校准 / 视觉验收工具，不再阻塞本版 01–74 曲线收口。现版按 `docs/design.md` §7.2 的机器代理控制；报告必须写 `machine-controlled / human-uncalibrated`，不得把未执行的真人项勾成通过。LV.999 是隐藏彩蛋，永久排除于曲线实验，只在真机条件允许时另做可读性体验。

## 准备

1. 运行 `pnpm dev`，使用无历史记录的浏览器窗口。
2. 正常试玩入口：`http://localhost:5173/?game=chem&level=1`。
3. 纯视觉入口会隐藏游戏名、关卡名、状态栏、提示和操作区，只留下棋盘：
   - 弹射中心：`http://localhost:5173/?game=chem&level=26&blind=1`
   - 阶段护罩：`http://localhost:5173/?game=chem&level=33&blind=1`
4. 全程录屏或由观察者逐项记时。玩家主动要求提示前，不点击「提示一步」；要求后可以使用，但要记录发生在哪一关、为什么需要。

观察者统一只说一句开场白：

> 请边玩边说你觉得下一步会发生什么。看不懂时也请先说你哪里不懂；我不会告诉你答案。

## 量化难度曲线协议（与下方质性门槛并行）

下方 A–D 负责找“为什么误解”；本节负责估计“哪关对哪类玩家有多难”。两类证据不能互相替代。启动收集器后先访问 `/health`，再完成一关并检查 `/api/attempt` 的计数增加；只检查通关反馈不足以证明放弃 / 重开数据已经入库。

### 两个队列，两个问题

1. **自然进程队列（主曲线）**：玩家知情同意后，入口加 `?study=natural&assignment=<批次号>&telemetry=1`，所有人从 01 开始、教程开启、按正式顺序自由玩，允许随时停止。通关、重开、换关和离开都保留；这批数据回答“真实新玩家沿正式流程走到这里时有多难”，也是 Rasch 主模型唯一默认纳入的队列。不得删除中途退出者，否则会产生幸存者偏差。
2. **熟练度队列（关卡内在比较）**：玩家知情同意后，入口加 `?study=mastery&assignment=<批次号>&telemetry=1`；只招募已经完成目标关之前全部机制教学的玩家，在同一章节内随机化 4–8 张目标关的顺序。它回答“掌握规则后，题本身有多难”，用于诊断自然曲线中的尖峰究竟来自规则习得还是解题。该队列不混入主 Rasch 曲线，单独报告。

`blind=1` 视觉实验、关闭教程、观察者教学过的会话也不得混入自然进程主模型。动画档与键盘 / 触屏会随尝试记录；两种输入各自样本不足时只合并展示，不解释设备差异。
普通入口不会自动把尝试发出；`telemetry=1` 只可在说明收集字段、用途与退出方式并得到同意后加入。未配置端点时记录仍只保留在试玩设备本地。

### 样本门槛与停止规则

- 管线冒烟：5 人或 30 条记录只用于查漏报 / 重复上报，禁止据此调关。
- 模型最低门槛：至少 20 名独立玩家、100 条首次尝试、10 个有关卡数据；至少 10 人各玩过 5 关，且每个纳入关至少 8 个首次尝试。低于此门槛，报告必须保持 `uncalibrated`。
- 正式曲线：75 关每关至少 20 个独立首次尝试；任一拟调整的相邻关至少有 20 名同玩家配对样本。停止收集只看预先约定的样本数，不因中途结果“显著 / 符合预期”提前停。
- 先冻结 20% 玩家作为确认集；探索性调序、特征选择和 Ridge 正则选择不看确认集。改关后使用新玩家复测，不把已经见过旧版地图的玩家当首次尝试。

主指标是**无 solver 提示首次通关**；有效时间、撤销、无效输入、预演和主观星级是解释轴。按玩家 bootstrap 计算关卡区间；相邻关倒挂用同玩家配对随机置换，并对一批相邻比较做 Benjamini–Hochberg 校正。只有区间、效应量与错误类型共同指向同一问题时才调关，不按单个 p 值机械排序。

### 章节内随机化

熟练度队列的 `assignment` 由固定 seed 生成并提前落盘；同一批玩家使用相同目标关集合的不同顺序，使每关曝光数和相邻配对数尽量平衡。随机化只发生在玩家已经学会该章节规则之后；教学首现关仍保持正式顺序，因为“学规则的难度”本就是自然曲线的一部分。每批必须保留 1–2 张冻结锚点关，改版候选与锚点使用同一批玩家、同一设备条件比较。

## A. 01–05 换入 / 换出门槛

让玩家从 01 连续玩到 05。不要额外解释“染色”、手持不变式或臂的去向；界面原有提示属于被测教学的一部分。

在 level-05 的两次持珠进攻前分别记录玩家是否主动预测：

- 手里的珠会进入哪一条臂、翻转后落到哪个方向；
- 原开口臂的珠会不会回到手里、是什么颜色。

完成 level-05 后只问开放题：“你能用自己的话说说，手里有珠时撞入会发生什么吗？”不得提示“放入 / 换出”两个词。

通过标准：玩家无需选项或纠正，能同时表达“手中珠进入中心并随中心翻到对侧”和“原开口珠换到手中”。只说“会换颜色”或只说其中一条，不通过；回到 03–05 修改教学与反馈后重测新玩家。

## B. 弹射中心 / 护罩的 1 秒视觉门槛

这部分必须在玩家首次看到对应机制前执行。打开纯视觉入口，棋盘出现后 1 秒立即遮住屏幕。

弹射中心问题：

1. “刚才哪个中心和其他中心不一样？请指出位置。”
2. “你觉得它会把什么东西往哪个方向送出去？”

护罩问题：

1. “哪个中心现在不能直接影响？”
2. “罩上的数字表示它什么时候解除？”

通过标准：玩家在 1 秒观察后能指出菱形弹射中心；看到编号 `2` 后能说出“进入第 2 阶段 / 完成第 1 阶段后解除”。第二题允许不知道精确弹出颜色，但必须把常驻尾迹 / 双箭头理解为出射方向。任一失败都不勾选 P2，先修静态轮廓或编号映射后换新玩家重测。

## C. 各机制段首次接触记录

同一位玩家可以顺序覆盖所有段落，因为进入每段时仍未接触该段的新机制；也可以每段使用不同玩家，但不同玩家必须先掌握此前的基础规则。每段只抽取最小代表关，避免要求玩家把 50 关全部打完：

| 段落 | 代表关 | 至少观察的预测 |
| --- | --- | --- |
| 01–06 核心搬运 | 03–06 | 持珠进攻后的放入色、换出色与最终方向；06 在无自动解释下能否自行发现先拿珠会改变后续撞入结果 |
| 07–12 共振 | 07–09 | 两拍规则教学后能否预测哪些相邻中心会翻、传播使用翻转前还是翻转后颜色；09 不开 hint 时能否自己发现共振可以影响碰不到的中心 |
| 13–17 光照 / 分步 | 13–15 | 光只转开口；阶段推进后当前目标如何变化 |
| 18–23 空穴 | 18 / 19 / 21 | 空穴翻到哪侧、哪条共振支路因此接通或断开 |
| 24–29 弹射 | 24–26 | 手是否清空、顶出珠颜色、路径与落点 |
| 30–36 阶段护罩 | 30–32 | 完成当步是否追溯传播、下一步哪些节点才开放 |
| 37–43 终盘新关系 | 37 / 39–41 / 43 | 弹射珠撞中心会触发什么；能否沿常显控制线指出控制臂；何时应主动关盾挡共振 / 飞珠；40 的闭→开→闭→开能否逐步预测；43 互补双闸换通行权 |
| 44–50 综合 mastery | 45 / 49 / 50 | 能否在不学新字段的情况下复用弹射资源、阶段预调和三路闸门；50 的三阶段计划是否卡在推理而非记忆 |
| 51–56 通关后·进阶综合 | 51–56 中的相邻配对 | 能否在组合规则下准确预测关键链路；新增关系是否带来新推理，而非只增加步骤或 UI 解码 |

每段必须留下以下四项事实，而不是“好玩 / 不好玩”的总体印象：

1. 首次误解：玩家第一句错误预测；若没有，明确写“无”。
2. 下一步预测：在执行该段第一个关键动作前，逐项记录预测与实际是否一致。
3. 卡点分类：`推理`（知道规则但没找到策略）/ `记忆`（忘记已有状态或刚才计划）/ `规则`（无法预测系统行为）/ `操作`（输入或 UI 没看懂）。
4. 辅助使用：是否打开文字提示、一步预演、Inspect、标记或 solver 提示，以及使用后是否能继续独立预测。

通过标准：每段至少一名合格玩家有完整记录；教学关结束后能在不经观察者解释的情况下正确预测该段关键动作。若主要卡点是 `记忆` 或 `规则`，该段不通过，优先修 UI / 教学；`推理` 卡点可以保留为谜题难度，但仍要判断是否发生在设计预期的位置。

## D. 51–56 赛后进阶段验证

51–56 已正式保留，不再做删选；与职责最接近的主线关成对验证只用于修关：36↔51、50↔52、41↔53、42↔54、44↔55、45↔56。每组记录首通用时、撤销次数、提示使用、关键动作预测错误数，以及玩家在不知道编号意义时更愿意重玩哪一张、理由是什么。

若未来取得样本，满足任一条件即可进入返工 / 重排名单：关键机制可被等长绕开；与对照关的推理轨迹同构且没有更清楚的反馈；最长通勤只增加执行时间；主要错误来自记忆或界面解码；同组关在两名玩家中都被明确判为较弱。51–74 已正式化，不因单轮偏好直接删关；真人结果用于校正现有机器代理顺序与降噪。
