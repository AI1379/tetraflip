# 《109.5°》v3.2 真人盲测协议

本协议只验证 `AGENTS.md` 中不能由 solver、单元测试或截图审查替代的三项真人门槛。受试者必须此前没有看过本项目、规则文档、关卡解或开发演示；开发者只观察和追问，不教学、不纠正。

## 准备

1. 运行 `pnpm dev`，使用无历史记录的浏览器窗口。
2. 正常试玩入口：`http://localhost:5173/?game=chem&level=1`。
3. 纯视觉入口会隐藏游戏名、关卡名、状态栏、提示和操作区，只留下棋盘：
   - 弹射中心：`http://localhost:5173/?game=chem&level=30&blind=1`
   - 阶段护罩：`http://localhost:5173/?game=chem&level=36&blind=1`
4. 全程录屏或由观察者逐项记时。玩家主动要求提示前，不点击「提示一步」；要求后可以使用，但要记录发生在哪一关、为什么需要。

观察者统一只说一句开场白：

> 请边玩边说你觉得下一步会发生什么。看不懂时也请先说你哪里不懂；我不会告诉你答案。

## A. 01–05 换入 / 换出门槛

让玩家从 01 连续玩到 05。不要额外解释“染色”、手持不变式或臂的去向；界面原有提示属于被测教学的一部分。

在 level-05 的两次持珠进攻前分别记录玩家是否主动预测：

- 手里的珠会进入哪一条臂、翻转后落到哪个方向；
- 原开口臂的珠会不会回到手里、是什么颜色。

完成 level-05 后只问开放题：“你能用自己的话说说，手里有珠时撞入会发生什么吗？”不得提示“放入 / 换出”两个词。

通过标准：玩家无需选项或纠正，能同时表达“手中珠进入中心并随中心翻到对侧”和“原开口珠换到手中”。只说“会换颜色”或只说其中一条，不通过；回到 03–05 修改教学与反馈后重测新玩家。

## B. 弹射中心 / 护罩的 1 秒视觉门槛

这部分必须在玩家首次看到对应机制前执行。打开纯视觉入口，棋盘出现后 1 秒立即遮住屏幕。

弹射中心问题：

1. “刚才哪个中心和其他中心不一样？请指出位置。”
2. “你觉得它会把什么东西往哪个方向送出去？”

护罩问题：

1. “哪个中心现在不能直接影响？”
2. “罩上的数字表示它什么时候解除？”

通过标准：玩家在 1 秒观察后能指出菱形弹射中心；看到编号 `2` 后能说出“进入第 2 阶段 / 完成第 1 阶段后解除”。第二题允许不知道精确弹出颜色，但必须把常驻尾迹 / 双箭头理解为出射方向。任一失败都不勾选 P2，先修静态轮廓或编号映射后换新玩家重测。

## C. 各机制段首次接触记录

同一位玩家可以顺序覆盖所有段落，因为进入每段时仍未接触该段的新机制；也可以每段使用不同玩家，但不同玩家必须先掌握此前的基础规则。每段只抽取最小代表关，避免要求玩家把 42 关全部打完：

| 段落 | 代表关 | 至少观察的预测 |
| --- | --- | --- |
| 01–10 核心搬运 | 03–05 | 持珠进攻后的放入色、换出色与最终方向 |
| 11–17 共振 | 11–13 | 哪些相邻中心会翻、传播使用翻转前还是翻转后颜色 |
| 18–23 光照 / 分步 | 18–20 | 光只转开口；阶段推进后当前目标如何变化 |
| 24–29 空穴 | 24 / 25 / 28 | 空穴翻到哪侧、哪条共振支路因此接通或断开 |
| 30–35 弹射 | 30–32 | 手是否清空、顶出珠颜色、路径与落点 |
| 36–42 阶段护罩 | 36–38 | 完成当步是否追溯传播、下一步哪些节点才开放 |

每段必须留下以下四项事实，而不是“好玩 / 不好玩”的总体印象：

1. 首次误解：玩家第一句错误预测；若没有，明确写“无”。
2. 下一步预测：在执行该段第一个关键动作前，逐项记录预测与实际是否一致。
3. 卡点分类：`推理`（知道规则但没找到策略）/ `记忆`（忘记已有状态或刚才计划）/ `规则`（无法预测系统行为）/ `操作`（输入或 UI 没看懂）。
4. 辅助使用：是否打开文字提示、一步预演、Inspect、标记或 solver 提示，以及使用后是否能继续独立预测。

通过标准：每段至少一名合格玩家有完整记录；教学关结束后能在不经观察者解释的情况下正确预测该段关键动作。若主要卡点是 `记忆` 或 `规则`，该段不通过，优先修 UI / 教学；`推理` 卡点可以保留为谜题难度，但仍要判断是否发生在设计预期的位置。
